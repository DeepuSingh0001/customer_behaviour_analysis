# Customer Shopping Behavior Analysis

## 📌 Overview
This project analyzes customer shopping behavior to identify purchasing trends, customer segments, and key factors influencing buying decisions. The analysis combines Python, SQL, and Power BI to generate actionable business insights.

## 📊 Dataset
The dataset contains customer shopping information such as:
- Customer demographics
- Product categories
- Purchase details
- Discounts
- Reviews
- Payment methods
- Shopping channels

## 🛠️ Tools & Technologies
- Python – Data Cleaning & EDA
- Pandas – Data Manipulation
- SQL – Data Analysis & Business Queries
- PostgreSQL – Database Management
- Power BI – Interactive Dashboard
- Excel – Supporting Analysis

## 🔍 Project Steps
1. Loaded and explored the dataset using Python.
2. Performed data cleaning and preprocessing.
3. Conducted Exploratory Data Analysis (EDA).
4. Loaded the cleaned data into PostgreSQL.
5. Used SQL queries to analyze customer behavior and purchasing patterns.
6. Built an interactive Power BI dashboard.
7. Prepared a detailed project report and presentation.

## 📈 Dashboard
The Power BI dashboard provides insights into:
- Customer purchasing trends
- Top-performing products
- Customer segments
- Discount behavior
- Purchase patterns
- Payment preferences

## 💡 Key Results
The analysis helps identify important customer behavior patterns and provides insights that can support:
- Better marketing strategies
- Improved customer engagement
- Product optimization
- Data-driven business decisions
